Use this documentation to install Rottweiler, complete a first task, automate
work, configure providers and security, extend the product, and integrate its
public APIs.

## Choose a path

- New to Rottweiler? Start with [Installation](./installation.md) and then run a
  [first session](./first-session.md).
- Ready to automate? Follow [Automate a task](./tutorials/automate-a-task.md).
- Configuring models? Read [Providers](./providers.md) and
  [Models and routing](./guides/models-and-routing.md).
- Integrating another tool? Use the [MCP tutorial](./tutorials/connect-mcp.md) or
  browse the [Client API](./reference/client-api.md).
- Evaluating the security boundary? Read [Security and trust](./guides/security-and-trust.md).

## Agent entry points

- [`llms.txt`](/Rottweiler/llms.txt) is the compact documentation map.
- [`llms-full.txt`](/Rottweiler/llms-full.txt) concatenates every public page with
  its source owners.
- [`docs-index.json`](/Rottweiler/docs-index.json) is a versioned JSON catalog.
- `/raw/product/` contains frontmatter-free product Markdown.
